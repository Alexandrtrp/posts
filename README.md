# React + TypeScript + Vite

Запуск проекта npm run dev

Данные поступают с открытого API https://jsonplaceholder.typicode.com/posts.

Задача проекта рендер постов и переход по страницам по их страницам.

Для хранения локальной информации выбран стейт менеджер Redux Toolkit.
Для навигации используется React Router.
